# cosmos-chain-mimicker

🪞 A tool for mimicking transactions from a reference Cosmos chain

## Requirements

* Python 3.12.11+
* Cosmos binary in path
* Signer keys in keyring

## Installation

Python dependencies:

```
cosmos-chain-mimicker$ python -m venv .env
cosmos-chain-mimicker$ source .env/bin/activate
cosmos-chain-mimicker$ pip install -r requirements.txt
```

## Usage

1. Modify the configuration settings in `config.toml`
2. Run the server with `python -m src.main`
